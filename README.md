# VIPER: Variant Impact Predictor with Expert Reasoning

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

## Overview

Inborn Errors of Immunity (IEI) encompass over 500 rare genetic disorders characterized by significant phenotypic and genotypic heterogeneity, presenting substantial challenges for molecular diagnosis. Existing variant prioritization tools face limitations in interpreting complex genomic data alongside unstructured phenotypes, which restricts their diagnostic efficacy in clinical settings. VIPER (Variant Impact Predictor with Expert Reasoning) is an open-source Large Language Model (LLM) framework designed for pathogenicity prediction and phenotype-genotype association analysis in the context of rare diseases.

## Features

- **High Diagnostic Yield**: Achieves up to 92.20% diagnostic yield in IEI patients.
- **Top-10 Recall Performance**: Ensures a high recall rate of top-10 predictions.
- **Emerging Gene-Disease Associations**: Capable of identifying new gene-disease relationships not covered in training data.
- **Modular Architecture**: Designed for easy adaptation to other monogenic disorders.

## Environment Setup

VIPER requires Python >= 3.10 and the `swift==3.6.0` package ([A framework for LLM fine-tuning and inference](https://github.com/modelscope/ms-swift)). We recommend using Conda to create a reproducible environment that works across different CPU architectures (x86_64, aarch64).

## Example Usage

### 1. Download Model Weights

Download the VIPER model checkpoint from Hugging Face:

```bash
git lfs install
git clone https://huggingface.co/BGI-LHH/VIPER
```

The model will be saved into `./VIPER/` (or specify your own path).

### 2. Download Toy Test Set

Download the example test set from Zenodo:

```bash
wget https://zenodo.org/records/19913111/files/Testset-VIPER-toy.jsonl
# or use curl
curl -L -o toy_testset.jsonl https://zenodo.org/records/19913111/files/Testset-VIPER-toy.jsonl
```

> 🔗 DOI: [10.5281/zenodo.19913111](https://doi.org/10.5281/zenodo.19913111)

`Testset-VIPER-toy.jsonl` is a small-scale example derived from VCF files. It has been pre-processed using [VarAnno2LLM](https://github.com/VincentLHH/VarAnno2LLM) to include variant annotations and prompt embeddings, making it ready for direct inference with VIPER.

### 3. Run Inference

After activating the Conda environment (`conda activate viper`), execute the following command:

```bash
export nproc_per_node=1
export NPROC_PER_NODE=$nproc_per_node
export CUDA_VISIBLE_DEVICES=1        # use GPU 1, change as needed
export MASTER_PORT=29885

swift infer \
    --ckpt_dir ./VIPER \             # path to the downloaded model
    --model_type qwen3 \
    --attn_impl flash_attn \
    --infer_backend vllm \
    --val_dataset ./Testset-VIPER-toy.jsonl \
    --max_model_len 8192 \
    --max_new_tokens 2 \
    --temperature 0 \
    --logprobs true \
    --top_p 1 \
    --top_k -1
```

> **Notes**:
> - Adjust `--ckpt_dir` to your actual model path.
> - Change `CUDA_VISIBLE_DEVICES` to your available GPU index.
> - The inference results will be saved inside the model directory under `infer_result/` (as generated by `swift`).

The predictions will be stored in the ./VIPER/infer_result/ folder. Each test variant includes the predicted pathogenicity label (positive/negative) and confidence score (0~1).
